 # SkillMatch AI

## Жоба туралы
SkillMatch AI — жұмыс іздеушілердің дағдыларын бос жұмыс орындарының талаптарымен сәйкестендіретін веб-қосымша.

## Жобаның мақсаты
Үміткерлердің дағдыларын жұмыс берушілердің талаптарымен салыстырып, сәйкес вакансияларды табуды жеңілдету.

## Негізгі мүмкіндіктері
- Тіркелу және жүйеге кіру
- Үміткер профилін жасау
- Дағдыларды енгізу
- Вакансияларды жариялау
- Вакансияларды іздеу және сүзу
- Сәйкестік пайызын есептеу
- Жұмысқа өтінім жіберу

## Технологиялар
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- Git және GitHub

## Жоба кезеңі
8-апта: жобаны жоспарлау, негізгі беттерді анықтау және дерекқор құрылымын әзірлеу.
